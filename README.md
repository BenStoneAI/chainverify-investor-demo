# Chain Verify — VerifyAPI investor demo repository

This is the public, read-only target repository for Chain Verify's unauthenticated
`software_delivery` VerifyAPI demo endpoint (`POST /api/verify/demo`).

It exists so prospects can run a live VerifyAPI check against a real public repo
without needing credentials. Only read-only GitHub REST API calls are made against
this repo (commit metadata, diffs, PR status) — nothing here is executed.

See https://chainverify.org/verify-api for the product this demo showcases.
